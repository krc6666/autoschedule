## 日常使用

1. 在“配置”中维护人员、航班模板、岗位和规则，或导入配置模板。
2. 在“航班”中确认当天航班、时间、运力和岗位；也可以使用在线查询生成增删建议。
3. 选择工作日期并生成排班，在真实任务进度完成后查看班表、人员负荷和规则反馈。
4. 按需要拖拽换人、交换岗位、填写临时岗位或调整当日轮值。
5. 在“统计”中核对月度值班、CX航前、备勤和岗位承担次数，在“历史”中复核已归档班表。
6. 导出 Excel、离线 HTML 或 PNG；确认当天结果后可以仅归档，或“归档并排后天”。

不参加备勤的人员，可以在“配置 → 人员信息”中关闭“备勤资质”。关闭后，自动轮值、手工选择和值班备勤 Excel 导入都不会再把该人员安排为备勤；若合格人员不足，备勤席位会留空并提示。

每次点击“生成排班”或“重新排班”，系统只计算当前选中的日期，不会提前计算未来两三个班。当天需要自动安排的岗位和所有合格人员会放在一起考虑；一般会在 30 秒内完成。超过 30 秒或计算失败时不会采用半成品，原班表会继续保留；确实缺少合格人员的岗位可以留空，并显示原因。完成这一班后，再按顺序生成下个工作班即可。

规则页可设置“末班结束界线”，默认是 `23:00`。实际结束严格晚于该时间的督导、一号、申报和送资料按航班分别检查本月与最近 8 个归档工作班的次数，自动安排顺序固定为“督导 → 一号 → 申报 → 送资料”；前一类达到当前最佳结果后才考虑后一类，后一类不能破坏前一类的公平。低频督导优先留给督导岗位，督导资质人员的申报和送资料次数允许比其他人少 1 次。需要比较的次数相差 2 次以上且本班没有安排给低频人员时才显示黄色提醒。

督导、一号、申报、控制和送资料都按航班与岗位滚动轮换：所有合格人员轮完当前次数后，才开始下一轮。重点岗位次数优先于恢复、疲劳、普通岗位衔接和上一班轻重；但不会突破资质、人员状态、夜班、时间冲突、每日工时、值班或 `KE166` 锁定、岗位完整性和严格岗位衔接。

`TR121 / H02` 按“一号”计算，自动排班时每名合格人员每个自然月最多承担 2 次；全部合格人员都达到 2 次后，该岗位自动留空。这个上限只限制自动排班，排班员仍可人工拖拽超过 2 次。值班人员若安排到首选晚撤岗位会使一号次数差超过 1，系统会继续尝试下一个晚撤目标。

统计页提供统一的“末班重点岗位统计”。先选择航班，再查看该航班的督导、一号、申报和送资料四类月度次数、承担日期及最高/最低差值；`TR121 / H02` 按“一号”显示。页面一次只展开一个航班，每类保留具备对应岗位资质的正常常规人员；申报和送资料表会标出督导资质人员，公平差值主要比较非督导资质人员。

班表生成后，可以在排班工具栏点击“对比上一班”，直接在当前页面上方展开当前排班日期之前最近一个已归档工作日的只读班表。当前班表继续保留在下方；没有更早归档时按钮显示“暂无上一班记录”。对照内容使用现有历史归档数据，不会修改班表或重新计算排班。

排班计算期间可以继续查看页面和缩放班表；再次计算、切换行政支援、修改数据、导入或归档会提示等待当前任务完成，防止两个操作同时改动班表。当前任务无论成功或失败都会释放后台计算资源，之后可以直接重试。

## 页面入口

| 页面 | 用途                                           |
| ---- | ---------------------------------------------- |
| 总览 | 查看当前日期、航班、人员和排班状态             |
| 配置 | 维护人员、模板、岗位和通用参数，导入或导出配置 |
| 航班 | 管理当天航班并进行线上计划对账                 |
| 排班 | 生成、复核、人工调整和导出当天班表             |
| 规则 | 用中文查看、启停和调整允许配置的排班规则       |
| 统计 | 管理月度轮值并核对人员与岗位统计               |
| 历史 | 查看、导入、删除和清空已归档排班               |

班表根据当前航班和岗位自动生成。航班增加到 5、6、7、8 个或更多时会继续扩展，超过可读宽度后仅班表区域横向滚动；当日轮值在桌面端固定显示于班表右侧，窄屏时自动移到班表上方。

业务数据默认保存在当前浏览器本地，配置和历史 Excel 也只在当前设备中解析。应用没有账号或远端数据写入。

详细规则、数据边界、实现说明和验收标准统一以 [spec.md](./spec.md) 为准，README 不重复维护第二套说明。

## 本地开发

安装依赖并启动开发服务：

```powershell
npm.cmd ci
python dev.py
```

检查生产构建：

```powershell
python dev.py --preview
```

完整验证：

```powershell
npm.cmd run verify
```
