# 国际航班查询工具

双击 `启动查询工具.cmd`，浏览器会打开 `http://127.0.0.1:4178`。

输入出发机场的 IATA 三字代码和日期，设置“当日凌晨排除至”和“次日凌晨截止”后点击“查询航班”。工具读取 FlightStats 的出港计划页面，排除目的地为中国大陆（`CN`）的航班；香港、澳门、台湾默认保留，可在页面中取消勾选。

## 说明

- 计划航班来源：FlightStats 出港页面。
- 全天读取：工具会读取前一晚、当天早中晚的重叠时间段；选择次日 06:00 以后截止时，也会读取次日早段。它按出发机场时区把跨日航班归到正确的起飞日期。
- 时间筛选：当日凌晨排除至 `06:00` 时，所选日期 00:00-05:59 起飞的航班不显示；次日凌晨截止 `06:00` 时，次日 00:00-05:59 起飞的航班会显示。
- 航司筛除：航班号以 `CA`、`MU`、`CZ` 开头的记录固定不显示。
- 共享与货运筛除：FlightStats 标记为“由其他航司执飞”的共享航班固定不显示；常见中外货运承运人按航司代码和名称筛除。客运航司使用同一航司代码执飞货机、但 FlightStats 未标明货运承运人的情况无法可靠区分。
- 航班号：保留 FlightStats 返回的共享航班号，并在航司栏标出实际承运信息；相同航班号、起飞时间和目的地的重复记录会自动合并。
- 机场国家/地区识别：随工具提供的 OurAirports 机场对照表，辅以 OpenFlights 对照表，用于判断目的地是否中国大陆。未识别的目的地不会被列为国际/地区航班，页面会明确提示。
- 计划时刻可能发生取消、延误或变更，临近起飞请以航空公司或机场发布的信息为准。
- 工具为本地服务，不会把查询条件或结果上传到其他服务；但查询时会从 FlightStats 读取公开班表。
